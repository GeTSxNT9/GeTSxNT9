### 🧭 ABOUT ME

I'm an IT enthusiast who builds practical tools with the help of AI.

I don't come from a formal programming background. Instead, I focus on **identifying problems, defining how a solution should work, and using AI-assisted development to turn those ideas into functional software**.

### 🎯 HOW I WORK

- **Problem First:** Start with a real need, workflow, or repetitive task.
- **Design:** Define the desired behavior, rules, interface, and user experience.
- **AI-Assisted Building:** Use AI to generate, modify, explain, and refine the underlying code.
- **Iteration:** Test the result, identify problems, adjust requirements, and iterate until the tool behaves as intended.
- **Practicality:** Prefer lightweight, focused solutions over unnecessary complexity.

### ⭐ FEATURED PROJECT

#### 📖 GastroOS

> **Web-based Operating System for Recipe Management, Menu Planning, Stock Control & Production Workflows.**

A client-side Progressive Web App created to centralize kitchen operations in a single interface.

- **Architecture:** Client-side PWA built with HTML5, CSS, and JavaScript.
- **Planning:** Custom constraint-based engine for weekly menu generation and validation.
- **Data:** Local-first persistence using browser `localStorage`.
- **Synchronization:** Optional recipe synchronization through the GitHub REST API.
- **Deployment:** Static application deployable through GitHub Pages.
